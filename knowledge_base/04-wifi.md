# Wi-Fi Connectivity
approval_status: approved

Steps:
1. Check whether other approved devices can connect.
2. Confirm Airplane Mode is off and Wi-Fi is enabled.
3. Select the corporate SSID and complete approved sign-in.
4. Move closer to an access point and retry once.
5. Forget and rejoin the network only if IT policy permits.
6. Capture the error without credentials.

Escalate to Network Support if multiple users are affected or authentication fails.
