# Printer Troubleshooting
approval_status: approved

Steps:
1. Confirm the printer is powered on and has no visible error.
2. Check computer and printer connectivity to the approved network.
3. Verify the correct printer queue.
4. Check whether the print job is paused or blocked.
5. Retry with a small test page if permitted.

Contact desktop support for persistent queue errors, hardware warnings, or access restrictions.
