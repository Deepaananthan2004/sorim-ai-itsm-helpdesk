# Password Reset and Account Unlock
approval_status: approved

Steps:
1. Use the organization's approved self-service password reset portal.
2. Verify identity using the configured process.
3. Follow the portal instructions and create a unique password meeting company policy.
4. If the account remains locked, use the approved unlock workflow or contact Identity Support.
5. Retry sign-in after the portal confirms reset or unlock.

Escalate if identity verification fails or repeated sign-in failures continue. Never share passwords or verification codes.
