# Software Installation
approval_status: approved

Steps:
1. Search the approved enterprise software catalog.
2. Review eligibility, supported platform, and approval requirements.
3. Submit a request with a work-related justification.
4. Wait for required approval.
5. Use managed deployment status to confirm installation.

Do not download enterprise software from unapproved sources or bypass administrator controls. Contact the service desk if the catalog item is unavailable or deployment fails.
