# Multi-Factor Authentication Issues
approval_status: approved

Steps:
1. Confirm device time is accurate and automatic.
2. Use only the official organization authentication prompt.
3. Check that the registered authenticator device is available.
4. Do not approve unexpected sign-in requests.
5. If a device was lost or replaced, use the approved identity recovery process.

Contact Identity Support for lost devices, repeated failures, or suspicious prompts. Never disclose one-time codes.
