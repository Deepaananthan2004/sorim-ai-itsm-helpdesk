# Application Access
approval_status: approved

Steps:
1. Confirm the correct organization account is selected.
2. Check the approved identity portal for assigned application access.
3. Complete multi-factor authentication through the official prompt.
4. Capture the error and application URL, excluding tokens and secrets.
5. Submit an access request if the application is not assigned to your role.

Application owners or Identity Support must approve access according to least-privilege policy.
