# Outlook Synchronization Troubleshooting
approval_status: approved

Steps:
1. Check internet connectivity and the IT-approved service status page.
2. Confirm Outlook is not in Work Offline mode.
3. Review the Outbox for a message blocked by a large attachment.
4. Restart Outlook and allow a few minutes for synchronization.
5. Check whether the issue also occurs in approved webmail.
6. Record the error and approximate time.

Escalate if the issue persists, affects multiple devices, or includes repeated authentication prompts.
