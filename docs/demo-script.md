# Live demo script (15–20 minutes)

1. **Business challenge (2 min):** repetitive IT tickets, slow triage, and fragmented knowledge.
2. **Architecture (3 min):** React → FastAPI → classification/RAG/workflow services → persistence and ServiceNow adapter.
3. **VPN incident (2 min):** enter “My VPN is not connecting and authentication keeps failing.” Show Network/VPN, P2, Network Support, sources, mock incident ID, audit.
4. **Self-heal (2 min):** submit “My password has expired.” Show authorization/approval, simulated action, validation, audit.
5. **RAG (2 min):** ask about Outlook synchronization and show retrieved sources.
6. **Provisioning (2 min):** request Visual Studio Code; show request reference and simulated completion.
7. **Unknown question (1 min):** ask for confidential payroll credentials; show refusal/escalation.
8. **Governance (2 min):** explain approved knowledge, thresholds, allowlisted actions, mock vs real integrations, and future hardening.
